    Phase A · about 10 minutes

    Run the finished project first

    See what you are building before you build it. The finished, tested project is in study/practice/barako-brew/.

    A1Install the two tools you need to run it

    Node.js, Git and VS Code must already be installed. Then:

    1. In VS Code, open the Extensions panel (Ctrl/Cmd+Shift+X), search Live Server (by Ritwick Dey), install it.
    2. In a terminal, install the mock API server:
    npm install -g json-server@0.17.4
    Error “running scripts is disabled”? Run Set-ExecutionPolicy -Scope Process Bypass -Force in that PowerShell window, then try again.

    A2Start the mock API

    In VS Code: File → Open Folder… → choose study/practice/barako-brew. Open the terminal (Ctrl+`) and run:

    json-server --watch db.json --port 3000
    Check: open http://localhost:3000/menu in the browser. You see 6 menu items as JSON. Leave this terminal running.

    A3Open the site with Live Server

    Right-click index.html → Open with Live Server. Never double-click the file: fetch() does not work from file://.

    Try everything:

    • Click Hot, Cold, Pastry. Reload: your last filter is remembered (cookie).
    • Search “latte”, then clear it.
    • Add items: they appear under Your order. Use − / +, tick the Senior citizen / PWD discount and watch the total change. Ube Frappe is “Sold out”.
    • Click Checkout: try pickup 05:00 (error), then a valid time. Press Esc to close the modal.
    • Send the contact form empty (error), then filled in (success). Look in db.json: your message is saved under "messages".
    • Make the window narrow: 1 card per row and the navbar folds into a menu button. Wider: 2, then 3 cards per row, and the order summary moves beside the lines.
    • Scroll to Budget picks: the small part built with Vue.js. Move the slider; the list updates instantly.
    Expected: one red Console error about a blocked inline script. That's Live Server's reload script being blocked by your Content Security Policy, which proves the CSP works. Just reload manually after edits.

    A4Prove it works offline

    1. Stop json-server (Ctrl+C) and reload the page. The menu still shows: it comes from data/menu.json.
    2. Turn Wi-Fi off and reload. Vue can't come from the Cloudflare CDN, so the page loads vendor/vue.global.prod.js instead. Budget picks still works.
    This is your exam situation. If the menu and Budget picks work with the API off and Wi-Fi off, the design is safe.

    L3The grid: container → row → col

    15 min
    1. .container centres the content with side padding (.container-fluid = full width).
    2. .row starts a line of columns. Only columns go directly inside a row.
    3. A row has 12 columns. col-4 takes 4 of 12 (a third), col-6 half, col-12 full width. Plain col shares the space equally; col-auto is as wide as its content.
    4. Your content goes inside the column. Spacing between columns comes from gutter classes on the row: g-0 … g-5.
    5. If the numbers add up to more than 12, the extra columns wrap to the next line. That's how cards flow into rows.

## 3. Feasibility and scalability

- **Resources:** all tools are free and installed during setup, so the project is feasible.
- **Budget:** no licence costs; effort 7.6 person-hours.
- **Schedule:** 7.6 hours of work fits the 8-hour window.

## 4. Software development methodology

**Selected: Agile, tailored.** One 8-hour sprint is split into 8 small increments. Each increment is committed to Git and checked against the requirements.

- **Why:** the back-end is not ready and the owner will add features later, so requirements will change. Agile delivers working parts early and accepts change.
- **Rejected:** Waterfall, because it assumes fixed requirements. RAD, because the owner is not available for repeated prototype reviews.
- **Tailoring for a one-person team:** the daily stand-up becomes a short check after each increment; the sprint review is the test report and owner sign-off.

// ----- Session management (simulated on the front end) -----
/** Ends the session after 15 idle minutes; otherwise records activity. */
function touchSession() {
  const now = Date.now();
  const last = Number(sessionStorage.getItem('lastActivity'));
  if (last && now - last > SESSION_IDLE_MS) {
    sessionStorage.clear();                 // expiry: drop session data and the old CSRF token
  }
  sessionStorage.setItem('lastActivity', String(now));
}

/**
 * Returns this session's CSRF token, creating a random one if needed.
 * A real server issues and checks this token; here we simulate both sides.
 * @returns {string}
 */
function getCsrfToken() {
  let token = sessionStorage.getItem('csrfToken');
  if (!token) {
    const bytes = crypto.getRandomValues(new Uint8Array(16));
    token = Array.from(bytes, b => b.toString(16).padStart(2, '0')).join('');
    sessionStorage.setItem('csrfToken', token);
  }
  return token;

/**
 * The customer's order: menu items with quantities, and the price computation.
 * total = subtotal - discount, where subtotal = sum of (price x quantity).
 */
class Cart {
  static MAX_QTY = 20;
  static DISCOUNT_RATE = 0.2;   // senior citizen / PWD, simplified practice rule

  constructor() {
    /** @type {{item: {id: number, name: string, price: number}, qty: number}[]} */
    this.lines = [];
    this.discounted = false;
  }

  /**
   * Adds one of an item, or one more if it is already in the cart (up to MAX_QTY).
   * @param {{id: number, name: string, price: number}} item
   */
  add(item) {
    const line = this.lines.find(l => l.item.id === item.id);
    if (line) line.qty = Math.min(line.qty + 1, Cart.MAX_QTY);
    else this.lines.push({ item, qty: 1 });
  }

  /**
   * Sets a quantity. Below 1 removes the line; blank or not a number is ignored.
   * @param {number} id
   * @param {number | string} qty
   */
  setQty(id, qty) {
    if (String(qty).trim() === '') return;
    const n = Math.trunc(Number(qty));
    if (!Number.isFinite(n)) return;
    if (n < 1) { this.remove(id); return; }
    const line = this.lines.find(l => l.item.id === id);
    if (line) line.qty = Math.min(n, Cart.MAX_QTY);
  }

  /** @param {number} id */
  remove(id) {
    this.lines = this.lines.filter(l => l.item.id !== id);
  }

  clear() {
    this.lines = [];
  }

  /** Number of items (sum of quantities). */
  get count() {
    return this.lines.reduce((sum, l) => sum + l.qty, 0);
  }

  get subtotal() {
    return roundMoney(this.lines.reduce((sum, l) => sum + l.item.price * l.qty, 0));
  }

  /** 20% of the subtotal, only when the box is ticked AND the cart is not empty. */
  get discount() {
    return this.discounted && this.lines.length > 0 ? roundMoney(this.subtotal * Cart.DISCOUNT_RATE) : 0;
  }

  get total() {
    return roundMoney(this.subtotal - this.discount);
  }
}

/**
 * Checks a pickup time ("HH:MM") for today: within opening hours (7:00-21:00)
 * and at least 15 minutes from now.
 * @param {string} value - from <input type="time">
 * @param {Date} [now]
 * @returns {string} an error message, or '' when the time is valid
 */
function validatePickup(value, now = new Date()) {
  if (!/^\d{2}:\d{2}$/.test(value)) return 'Choose a pickup time.';
  const [hours, minutes] = value.split(':').map(Number);
  const pickup = new Date(now);
  pickup.setHours(hours, minutes, 0, 0);
  const opens = new Date(now);
  opens.setHours(7, 0, 0, 0);
  const closes = new Date(now);
  closes.setHours(21, 0, 0, 0);
  const earliest = new Date(now.getTime() + 15 * 60 * 1000);

  if (pickup < opens || pickup > closes) return 'We are open from 7:00 to 21:00.';
  if (pickup < earliest) return 'Pickup must be at least 15 minutes from now.';
  return '';
}

 * Uses a render function (h) instead of a template, so Vue never compiles code in the

 * Vue loads from the Cloudflare CDN (cdnjs); offline, the local copy in vendor/ is used.

const PICKS_API = 'http://localhost:3000/menu';
const PICKS_LOCAL = 'data/menu.json';

/** Creates and mounts the Vue app once Vue is available. */
function startVueApp() {
  const { createApp, ref, computed, onMounted, h } = window.Vue;

  createApp({
    setup() {
      const items = ref([]);          // reactive state: the menu
      const maxPrice = ref(100);      // reactive state: the slider value
      const status = ref('Loading...');

      // Load the menu once: API first, local JSON copy when the API is down
      onMounted(async () => {
        try {
          let res = await fetch(PICKS_API).catch(() => null);
          if (!res || !res.ok) res = await fetch(PICKS_LOCAL);
          if (!res.ok) throw new Error(`HTTP ${res.status}`);
          items.value = await res.json();
          status.value = '';
        } catch (err) {
          console.error('Budget picks failed:', err);
          status.value = 'Budget picks are unavailable.';
        }
      });

      // Recalculated automatically whenever items or maxPrice change
      const picks = computed(() =>
        items.value.filter(item => item.available && item.price <= maxPrice.value));

      // h(tag, attributes, children) builds the same elements a template would.
      // Text is set as text, so Vue escapes it (output encoding, no XSS).
      // Bootstrap classes: card, form-range, list-group, d-flex justify-content-between.
      return () => h('div', { class: 'card picks' }, [
        h('div', { class: 'card-body' }, [
          h('label', { for: 'max-price', class: 'form-label' }, `Show items up to PHP ${maxPrice.value}`),
          h('input', {
            id: 'max-price', type: 'range', class: 'form-range', min: 40, max: 160, step: 10, value: maxPrice.value,
            onInput: e => { maxPrice.value = Number(e.target.value); }
          }),
          h('p', { role: 'status', class: 'text-body-secondary mb-2' }, status.value || `${picks.value.length} item(s) available`)
        ]),
        h('ul', { class: 'list-group list-group-flush' }, picks.value.map(item =>
          h('li', { key: item.id, class: 'list-group-item d-flex justify-content-between' }, [
            h('span', item.name),
            h('span', `PHP ${item.price.toFixed(2)}`)
          ])))
      ]);
    }
  }).mount('#budget-picks');
}

## 4. Framework and CSP

Vue.js can compile templates in the browser, which needs `'unsafe-eval'` in the CSP. To avoid that, the Budget picks component uses a render function (`h()`), so the CSP stays strict on the whole site. Tested: a template version is blocked by the CSP; the render-function version runs with no CSP errors.

## 5. Back-end phase (authentication, sessions, transmission)

- **Authentication:** hashed passwords, OTP / step (two-factor) authentication for staff, hardware tokens (YubiKey, SecurID) or biometrics for admins, digital certificates, SSH keys for server access.
- **Authorisation:** role-based access (owner, staff). Hiding admin buttons is a UI restriction only; the server must check every request.
- **Sessions:** unique random session IDs, expiration, a new ID after login, cookies with Secure + HttpOnly + SameSite=Strict, session auditing and monitoring.
- **Transmission:** HTTPS (TLS) everywhere with security headers: Content-Security-Policy, Strict-Transport-Security, X-Frame-Options (or CSP `frame-ancestors`), X-Content-Type-Options: nosniff.

    # User Guide — Barako Brew Website

For café staff and the owner. No technical knowledge needed.

## View the menu

Open the website. The menu loads by itself. Items that are sold out show a grey "Sold out" button.

Click All, Hot, Cold or Pastry above the menu. The highlighted button is the one in use. The site remembers your choice for 30 minutes.

Type part of a name in "Search the menu", for example "latte". It works together with the category buttons.

Click "Add to order" on an item. The number beside "Cart" at the top goes up, and the item appears under "Your order".

Click Checkout, enter the name for pickup and a pickup time today between 7:00 and 21:00, at least 15 minutes from now, then Confirm order.

Move the slider under "Budget picks" to see the available items up to that price.

Customers fill in their name, email and message and tick the privacy box. Messages are saved by the server (for now in db.json under "messages").
